# Landing Page — Portfólio Pessoal

Projeto acadêmico desenvolvido durante o curso de **Análise e Desenvolvimento de Sistemas (ADS)** na UniCesumar.

A página apresenta um portfólio pessoal responsivo criado para praticar fundamentos de desenvolvimento web e organizar informações sobre minha trajetória, habilidades e projetos.

## Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Design responsivo

## O que pratiquei neste projeto

- Estruturação semântica de uma página HTML
- Estilização com CSS
- Organização de conteúdo em seções
- Layout com Grid e Flexbox
- Adaptação da interface para dispositivos móveis
- Links de navegação interna e externa

## Status

🚧 Projeto acadêmico em evolução. Novas melhorias serão adicionadas conforme avanço nos estudos de desenvolvimento web.
